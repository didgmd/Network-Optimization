# DRL PCI

Open-source implementation accompanying the paper:

**Adaptive PCI Allocation in Heterogeneous Networks: A DRL-Driven Framework With Hash Table, FAGA, and Guiding Policies**

## Package structure

```text
src/                         DRL-based PCI allocation runtime
├── PCI_DRL_main.py          Main training entry point
├── Parameters.py            Simulation and optimization parameters
├── NetworkTopology.py       Heterogeneous-network topology construction
├── NeighborList.py          Neighbor-relation construction
├── PciAllocation.py         PCI pools and initial allocation
├── QNet.py                  Q-network and action/state utilities
├── CheckForCollision.py     PCI conflict detection
├── CheckForConfusion.py     PCI confusion detection
├── Normalization.py         State normalization
├── FigurePlotter.py         Runtime visualization utilities
├── DataSave.py              Runtime result export
└── DebugPrint.py            Debug/output utilities
figure_source_data/          Released manuscript figure-source data
requirements.txt             Python dependencies
LICENSE                      Source-code license
LICENSE-DATA                 Figure-source data license
```

## Runtime components

The released implementation preserves the available research code associated with the DRL-based PCI-allocation framework, including:

- heterogeneous eNB/gNB topology generation and neighbor construction;
- PCI conflict detection for eNB modulo 30/6/3 and gNB modulo 30/4/3 cases;
- PCI confusion detection for both eNB and gNB neighborhoods;
- hash-based initial PCI allocation using node identifiers and iteration-dependent mapping;
- experience-pool-assisted action evaluation and epsilon-greedy action selection;
- Multi-Objective Simulated Annealing (MOSA) for action determination across eight PCI optimization objectives;
- PCI reassignment with reuse-distance checks;
- guided target Q-value calculation focused on selected PCI-adjustment actions;
- Fitness-Aided Genetic Algorithm (FAGA) based adaptation of learning rate, greediness, and discount factor;
- Huber-loss optimization and exponential-moving-average loss tracking;
- runtime visualization and spreadsheet result export.

## Reproducibility scope

The released implementation follows the core DRL-based PCI-allocation route described in the associated manuscript, including hash-based initialization, experience-assisted action evaluation, multi-objective action determination, guided target calculation, and FAGA-based parameter adaptation.

The package preserves the available research implementation and its original modular structure for reproducibility-oriented inspection and experimentation.

The default project configuration uses a 100 × 100 simulation area, 180 base-station nodes, a 30%/70% eNB/gNB deployment ratio, and a 180-100-180 Q-network. Runtime and optimization parameters are defined in `src/Parameters.py`, while PCI ranges are supplied interactively by `src/PCI_DRL_main.py`.

`figure_source_data/` contains the currently released source data for the principal numerical evaluation figures:

```text

```

Topology, PCI-allocation, and network-state visualizations without standalone CSV source files are not included as separate figure-source artifacts.

## Requirements

Install the Python dependencies listed in `requirements.txt`.

The main runtime can be started with:

```bash
python src/PCI_DRL_main.py
```

The program prompts for the eNB and gNB PCI ranges before constructing the network and starting the optimization workflow. Runtime figures and spreadsheet outputs may be generated by the visualization and export modules.
