# 07_CG-DQN_MRO data package

This release candidate contains the data surfaces used by the manuscript.

## Contents

- `ns3_dataset/20250424_trajectory_all/`: raw ns-3 trajectory and radio-measurement CSV outputs.
- `figure_source_data/`: CSV files used to generate the manuscript figures.

`MD5SUMS.txt` lists MD5 checksums for every file under `ns3_dataset/` and `figure_source_data/`. Paths are relative to this directory.
